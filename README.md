# NLP Sentiment Analysis using BERT

## Project Overview
A project that uses a BERT Model to identify sentiment in social media posts.

## Models Used
- Traditional ML Models: Naive Bayes, Logistic Regression, SVM
- Transformer Model: BERT (Fine-tuned)

## Results
| Model | Accuracy |
|-------|----------|
| Naive Bayes | 78% |
| Logistic Regression | 82% |
| SVM | 85% |
| BERT | 92% |

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run traditional models: `python src/train_models.py`
3. Run BERT: `python src/train_bert.py`

## Technologies
- Python, PyTorch
- Hugging Face Transformers
- Scikit-learn, NLTK
